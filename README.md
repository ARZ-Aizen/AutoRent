# AutoRent 🚗

AutoRent is a Windows Forms desktop application designed to streamline car rental operations. It provides a reliable interface for managing vehicle fleets, processing customer rentals, and tracking inventory availability using a lightweight Microsoft Access database.

## Features
* **Vehicle Inventory Management:** Add, update, and track the availability of rental vehicles.
* **Transaction Processing:** Log new rentals, calculate fees, and process returns.
* **Customer Records:** Maintain a local database of customer details and rental history.
* **Custom UI:** Clean, custom-styled interface featuring rounded containers and optimized layouts for intuitive navigation.

## Tech Stack
* **Language:** C#
* **Framework:** .NET Windows Forms (WinForms)
* **Database:** Microsoft Access (`AutoRent.accdb`)
* **IDE:** Visual Studio

## Prerequisites
* Visual Studio (with .NET desktop development workload installed)
* Microsoft Access Database Engine (required for `.accdb` OLEDB connections)
* Git (for version control)
